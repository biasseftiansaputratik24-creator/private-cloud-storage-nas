# Project Overview

## Nama Proyek
Perancangan Private Cloud Storage Berbasis NAS dengan Arsitektur Multi Tenant untuk Penyediaan Layanan Penyimpanan Data

## Deskripsi
Proyek ini membahas perancangan dan pengujian sistem private cloud storage berbasis Network Attached Storage (NAS). Sistem dirancang untuk melayani beberapa tenant dengan pemisahan data dan pengaturan hak akses.

## Tujuan
1. Mempelajari instalasi dan konfigurasi sistem NAS.
2. Menguji layanan penyimpanan melalui jaringan lokal.
3. Menerapkan pemisahan akses antar-tenant.
4. Mengukur performa transfer data.
5. Mendokumentasikan hasil pengujian.

PERANGKAT YANG KAMI PAKAI
- TrueNAS
- Debian
- OpenMediaVault
- SMB/CIFS
- Nextcloud (sesuai tahap implementasi)
- GitHub

Tahap Pengerjaan
Saat ini proyek berada pada tahap pengujian dan evaluasi sistem.

Hasil pengujian akan dilengkapi berdasarkan praktik yang benar-benar dilakukan.
